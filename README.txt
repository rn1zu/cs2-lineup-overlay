================================================================================
README: ВНЕШНИЙ ОВЕРЛЕЙ-ПРИЦЕЛ ДЛЯ CS2 (LINE-UP)
================================================================================


================================================================================
НАЗНАЧЕНИЕ
================================================================================

После обновления CS2 «Rush Hour» (сентябрь 2026) максимальная длина линий
прицела cl_crosshair_length ограничена 255 пикселями. Для точных раскидов
(line-up) этого недостаточно.

Данный README описывает, как создать и использовать внешний оверлей —
прозрачное изображение с длинными линиями, которое появляется поверх игры
по нажатию боковой кнопки мыши (mouse5).

Оверлей не внедряется в процесс игры, не читает её память и не изменяет
файлы. Он рисуется средствами Windows через AutoHotkey.

  ВАЖНО: Использование в рейтинговых матчах — на ваш страх и риск.
  На турнирах, где запрещены сторонние программы, оверлей использовать
  НЕЛЬЗЯ.


================================================================================
ЧТО ПОНАДОБИТСЯ
================================================================================

  1. Windows 10/11

  2. AutoHotkey v2 — скачать с официального сайта: https://www.autohotkey.com/

  3. Adobe Photoshop (или любой редактор с поддержкой PNG и прозрачности)

  4. CS2, запущенная в режиме «Оконный без рамки»
     (Windowed Fullscreen / Borderless).

     ВАЖНО: В режиме «Полный экран» (Full Screen) оверлей работать НЕ БУДЕТ.


================================================================================
ШАГ 1. ПОДГОТОВКА ИЗОБРАЖЕНИЯ ПРИЦЕЛА В PHOTOSHOP
================================================================================

1.1. Создайте новый документ:

       Ширина:            1920 px
       Высота:            1080 px
       Разрешение:        72 ppi
       Цветовой режим:    RGB, 8 бит
       Содержимое фона:   Прозрачный

     ВАЖНО: Обязательно выберите «Прозрачный» фон. Если выбрать «Белый»,
     прицел в игре закроет весь экран белым квадратом.


1.2. Включите направляющие:

       Просмотр -> Новые направляющие
         Вертикальная:   960 px
         Горизонтальная: 540 px


1.3. Нарисуйте линии инструментом «Прямоугольник» (клавиша U).

     Параметры линий:

       Толщина: как cl_crosshairthickness в CS2 (например, 2 пикс).
                Учтите, что обводка добавляет по 1 пикселю с каждой
                стороны, поэтому итоговая толщина будет больше.
                Можно сделать без обводки, но тогда линии будут
                хуже видны на светлом фоне.

       Цвет:    возьмите значения RGB из CS2.
                Например, для #4F00FF (R=79, G=0, B=255).

     Вертикальные полосы:

       Левая:   X = 959, Y = 0, Ш = 1, В = 1080
       Правая:  X = 960, Y = 0, Ш = 1, В = 1080

     Горизонтальные полосы (если нужен полный крест):

       Верхняя: X = 0, Y = 539, Ш = 1920, В = 1
       Нижняя:  X = 0, Y = 540, Ш = 1920, В = 1

     Зазор: в CS2 cl_crosshairgap можно поставить 0, тогда линии сойдутся.
            Если нужен зазор, сдвиньте полосы на 1-2 пикселя.

     ВАЖНО: Чтобы полосы были идеально ровными, вводите координаты
     через панель «Свойства» (X, Y, Ш, В), а не рисуйте мышкой.


1.4. Убедитесь, что фоновый слой выключен (не горит глазик).


1.5. Сохраните файл:

       Файл -> Экспортировать -> Экспортировать как...

         Формат:     PNG
         Галочка «Прозрачность» — обязательно.
         Имя файла:  lineup.png

       Сохраните в папку, где будет лежать скрипт
       (например, C:\Crosshairs\).

     ВАЖНО: Не сохраняйте в JPG — он не поддерживает прозрачность,
     и в игре появится тёмный или белый прямоугольник вокруг прицела.


================================================================================
ШАГ 2. УСТАНОВКА AUTOHOTKEY V2
================================================================================

2.1. Скачайте установщик v2.0 с официального сайта autohotkey.com.

2.2. Запустите установщик. Windows покажет предупреждение SmartScreen —
     нажмите «Подробнее» -> «Выполнить в любом случае».

     Это стандартное предупреждение для любых новых программ. Оно не
     означает, что в файле есть вирус.

2.3. Установите в любую папку. Можно на диск D — на работу это не влияет.

2.4. После установки закройте окно AutoHotkey Dash.


================================================================================
ШАГ 3. СОЗДАНИЕ СКРИПТА
================================================================================

3.1. В папке с картинкой lineup.png создайте новый текстовый файл.

3.2. Откройте его и вставьте следующий код:

--------------------------------------------------------------------------------
#Requires AutoHotkey v2.0
#SingleInstance Force
A_MenuMaskKey := "vkE8"    ; маскировка Win, чтобы не открывался Game Bar

; Настройки оверлея
OverlayAlpha := 180        ; Прозрачность (0-255)
OverlayX_Offset := 0       ; Смещение по X от центра
OverlayY_Offset := 0       ; Смещение по Y от центра
ImageFile := "lineup.png"  ; Имя файла с картинкой

; Получаем разрешение экрана
ScreenW := A_ScreenWidth
ScreenH := A_ScreenHeight

; Создаём окно
MyGui := Gui()
MyGui.Opt("+AlwaysOnTop -Caption +ToolWindow +LastFound +E0x80020")
MyGui.MarginX := 0
MyGui.MarginY := 0
MyGui.BackColor := "000000"
MyGui.Add("Picture", "x0 y0 w" ScreenW " h" ScreenH " BackgroundTrans", ImageFile)

; Прозрачность и клик-сквозность
WinSetTransColor("000000 " OverlayAlpha, MyGui)
WinSetExStyle("+0x20", MyGui)

; Показываем и сразу скрываем
MyGui.Show("x" (ScreenW/2 - (ScreenW/2) + OverlayX_Offset) " y" (ScreenH/2 - (ScreenH/2) + OverlayY_Offset) " w" ScreenW " h" ScreenH " NoActivate")
WinHide("ahk_id " MyGui.Hwnd)

; --- Горячие клавиши ---
; Показ оверлея при зажатии mouse5
XButton2:: {
    WinShow("ahk_id " MyGui.Hwnd)
}
; Скрытие при отпускании
XButton2 Up:: {
    WinHide("ahk_id " MyGui.Hwnd)
}

; Сворачивание игры по одиночному нажатию Win (если зажать — работает как модификатор)
LWin:: {
    if KeyWait("LWin", "T0.25")
        WinMinimize("A")
}

; Аварийный выход по F12
F12::ExitApp
--------------------------------------------------------------------------------

3.3. Сохраните файл с именем lineup_overlay.ahk (обязательно расширение
     .ahk, а не .txt).

     Если Windows скрывает расширения, включите их отображение в проводнике:
     Вид -> Показать -> Расширения имён файлов.

     ВАЖНО: Если файл сохранится как lineup_overlay.ahk.txt, скрипт
     не запустится. Проверьте расширение.


================================================================================
КАК ПОМЕНЯТЬ КНОПКУ АКТИВАЦИИ ОВЕРЛЕЯ
================================================================================

По умолчанию оверлей включается на mouse5 (это XButton2). Чтобы поставить
другую кнопку, найди в коде эти две строки:

    XButton2:: {
        WinShow("ahk_id " MyGui.Hwnd)
    }
    XButton2 Up:: {
        WinHide("ahk_id " MyGui.Hwnd)
    }

И замени XButton2 В ОБЕИХ СТРОКАХ на нужное значение из таблицы ниже.


================================================================================
ПОПУЛЯРНЫЕ ВАРИАНТЫ КНОПОК В AUTOHOTKEY V2
================================================================================

  Кнопка                                     Название в скрипте
  ----------------------------------------   -----------------
  Mouse4 (боковая, ближе к большому пальцу)  XButton1
  Mouse5 (боковая, дальше)                   XButton2
  Средняя кнопка мыши                        MButton
  Левая кнопка                               LButton
  Правая кнопка                              RButton
  Колесо вверх                               WheelUp
  Колесо вниз                                WheelDown
  Колесо влево                               WheelLeft
  Колесо вправо                              WheelRight
  Клавиша F                                  f
  Клавиша Space                              Space
  Клавиша V                                  v
  Клавиша H                                  h
  Клавиша CapsLock                           CapsLock
  Клавиши F1 - F12                           F1 ... F12
  Клавиша Tab                                Tab
  Левый Alt                                  LAlt
  Левый Ctrl                                 LCtrl
  Левый Shift                                LShift


================================================================================
ПРИМЕР: ПЕРЕНАЗНАЧИТЬ НА MOUSE4
================================================================================

Замени блок горячих клавиш на:

    XButton1:: {
        WinShow("ahk_id " MyGui.Hwnd)
    }
    XButton1 Up:: {
        WinHide("ahk_id " MyGui.Hwnd)
    }

После правки сохрани файл и сделай Reload Script через иконку H в трее.


================================================================================
ВАЖНО ПРИ ВЫБОРЕ КНОПКИ
================================================================================

  - Не назначай на кнопки, которые уже заняты в CS2 (стрельба, прыжок,
    приседание, гранаты, голос) — иначе будет конфликт.

  - Если ставишь на клавишу клавиатуры, убедись, что в игре на неё ничего
    не забиндено. Проверить можно в консоли: bind h покажет, что сейчас
    висит на клавише.

  - Пара «X::» и «X Up::» ОБЯЗАТЕЛЬНА. Если оставить только первую —
    оверлей включится и больше не выключится.


================================================================================
ШАГ 4. СОЗДАНИЕ .BAT-ПЕРЕКЛЮЧАТЕЛЯ (ВКЛ/ВЫКЛ ОДНОЙ КНОПКОЙ)
================================================================================

Чтобы не лазить по папкам и не кликать дважды, создайте .bat-файл, который
будет включать и выключать оверлей одним запуском.

4.1. На рабочем столе создайте текстовый файл и вставьте в него:

--------------------------------------------------------------------------------
@echo off
title Crosshair Overlay Toggle

tasklist /FI "IMAGENAME eq AutoHotkey64.exe" 2>NUL | find /I "AutoHotkey64.exe" >NUL
if "%ERRORLEVEL%"=="0" goto kill
tasklist /FI "IMAGENAME eq AutoHotkey32.exe" 2>NUL | find /I "AutoHotkey32.exe" >NUL
if "%ERRORLEVEL%"=="0" goto kill
goto start

:kill
taskkill /IM AutoHotkey64.exe /F >NUL 2>&1
taskkill /IM AutoHotkey32.exe /F >NUL 2>&1
echo Overlay OFF
timeout /t 1 >NUL
exit

:start
start "" "C:\CrosshairOverlay\lineup_overlay.ahk"
echo Overlay ON
timeout /t 1 >NUL
--------------------------------------------------------------------------------

4.2. Замените путь C:\CrosshairOverlay\lineup_overlay.ahk на свой реальный путь
     к файлу скрипта.

     ВАЖНО: Путь должен быть в кавычках. Если в пути есть пробелы,
     без кавычек .bat не сработает.

4.3. Сохраните файл и переименуйте его в Crosshair.bat (уберите .txt,
     добавьте .bat).

     Если Windows не даёт переименовать, включите отображение расширений.

4.4. Согласитесь на предупреждение «Файл может быть недоступен…» —
     нажмите «Да».

Теперь просто дважды кликайте по Crosshair.bat:

  - Если оверлей выключен — он запустится (иконка H в трее).
  - Если оверлей включён — он выключится (иконка исчезнет).


================================================================================
ГОРЯЧАЯ КЛАВИША ДЛЯ .BAT (ОПЦИОНАЛЬНО)
================================================================================

  1. Нажмите правой кнопкой по Crosshair.bat ->
     «Отправить» -> «Рабочий стол (создать ярлык)».

  2. На ярлыке: правой кнопкой -> «Свойства» ->
     поле «Быстрый вызов» -> нажмите желаемую комбинацию
     (например, Ctrl + Alt + X).

  3. Нажмите «ОК». Теперь оверлей можно включать/выключать с клавиатуры.


================================================================================
ШАГ 5. УПРАВЛЕНИЕ СКРИПТОМ
================================================================================

  - Запуск: дважды кликните по lineup_overlay.ahk.
    В трее появится зелёная иконка H.
    Если иконки не видно — нажмите стрелочку ^ рядом с часами, чтобы
    развернуть скрытые значки.

  - Перезапуск после правок: правый клик по иконке H -> Reload Script.

  - Выключение: правый клик по иконке H -> Exit.
    Или используйте .bat-переключатель, или команды taskkill (см. Шаг 6).

  ВАЖНО: Если выключить компьютер или перезагрузить его, скрипт сам
  не запустится. Каждый раз нужно запускать файл lineup_overlay.ahk
  вручную (или через Crosshair.bat) перед запуском CS2.


================================================================================
ШАГ 6. УПРАВЛЕНИЕ ПРОЦЕССОМ ЧЕРЕЗ КОНСОЛЬ (TASKKILL)
================================================================================

Если нужно принудительно завершить скрипт, откройте командную строку
(Win + R -> cmd) и выполните одну из команд:

    taskkill /IM AutoHotkey.exe /F
    taskkill /IM AutoHotkey64.exe /F
    taskkill /IM AutoHotkey32.exe /F

  - Если процесс не найден — это нормально, значит скрипт уже выключен.
  - В AutoHotkey v2 процесс обычно называется AutoHotkey64.exe
    (на 64-битной системе).
  - Команды не содержат имени пользователя, их можно копировать как есть.


================================================================================
ШАГ 7. ИСПОЛЬЗОВАНИЕ В CS2
================================================================================

  1. Запустите CS2.

  2. В настройках видео выберите режим «Оконный без рамки».

     ВАЖНО: В режиме «Полный экран» оверлей не будет виден. Это ограничение
     Windows, а не ошибка скрипта.

  3. Зажмите mouse5 — поверх игры появятся ваши линии.
     Отпустите — исчезнут.

  4. Для сворачивания игры нажмите Win (одиночное нажатие).
     Если зажать Win и нажать другую клавишу, сработает системная комбинация.


================================================================================
НАСТРОЙКИ СКРИПТА (ДЛЯ ТОНКОЙ ПОДГОНКИ)
================================================================================

В начале файла lineup_overlay.ahk можно изменить:

  OverlayAlpha  — прозрачность (0 — полностью прозрачный,
                  255 — непрозрачный). Оптимально 150-200.

  OverlayX_Offset, OverlayY_Offset
                — смещение оверлея от центра экрана в пикселях.
                  По умолчанию 0.

  ImageFile     — имя файла с картинкой, если вы назвали его иначе.

После правки сохраните файл и сделайте Reload Script через иконку H.


================================================================================
БЕЗОПАСНОСТЬ И VAC
================================================================================

  - Оверлей не внедряется в игру, не читает память, не изменяет файлы.
    Он использует только штатные функции Windows (прозрачное окно).

  - VAC не банит за внешние оверлеи, которые не дают нечестного
    преимущества (например, не показывают врагов через стены).

  - Использование в рейтинговых матчах остаётся на ваш риск.

  - НЕ используйте этот оверлей на турнирах, где запрещены любые
    сторонние программы.

  - Не запускайте .ahk-скрипты из непроверенных источников. Скачивайте
    AutoHotkey только с официального сайта autohotkey.com.


================================================================================
ДОПОЛНИТЕЛЬНО: СМЕНА ЦВЕТОВ ПРИЦЕЛА В ИГРЕ (CHCOLOR.CFG)
================================================================================

Если вы хотите быстро менять цвета прицела в CS2 через консоль,
можно использовать конфиг с алиасами. Пример:

--------------------------------------------------------------------------------
// chcolor.cfg
alias "chc0"  "cl_crosshaircolor 5; cl_crosshaircolor_r 250; cl_crosshaircolor_g 50;  cl_crosshaircolor_b 50;  echo crosshair: 0 red"
alias "chc1"  "cl_crosshaircolor 5; cl_crosshaircolor_r 50;  cl_crosshaircolor_g 250; cl_crosshaircolor_b 50;  echo crosshair: 1 green"
// ... и так далее
alias "chc_next" "chc_c0"
alias "chc_c0"  "cl_crosshaircolor 5; chc0;  alias chc_next chc_c1"
// ... полный цикл
bind "h" "chc_next"
--------------------------------------------------------------------------------

  - Для кастомных цветов обязателен cl_crosshaircolor 5.
  - Сохраните файл как chcolor.cfg (не .txt).
  - В консоли: exec chcolor.
  - Клавиша H будет переключать цвета по кругу.

  ВАЖНО: Алиасы (alias) в CS2 теперь работают только при загрузке через
  autoexec при запуске игры или вручную через консоль. Загрузить их
  через exec во время игры больше нельзя.
