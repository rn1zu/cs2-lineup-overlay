# Внешний оверлей-прицел для CS2 (Line-Up)

> Прозрачный оверлей с длинными линиями для точных раскидов.  
> Появляется по нажатию боковой кнопки мыши, не внедряется в игру.

## 🎯 Назначение

После обновления CS2 «Rush Hour» (сентябрь 2026) максимальная длина линий прицела `cl_crosshair_length` ограничена **255 пикселями**. Для точных раскидов (line-up) этого недостаточно.

Данный репозиторий описывает, как создать и использовать **внешний оверлей** — прозрачное изображение с длинными линиями, которое появляется поверх игры по нажатию боковой кнопки мыши (mouse5).

Оверлей **не внедряется** в процесс игры, не читает её память и не изменяет файлы. Он рисуется средствами Windows через AutoHotkey.

> ⚠️ **ВАЖНО:** Использование в рейтинговых матчах — на ваш страх и риск. На турнирах, где запрещены сторонние программы, оверлей использовать **нельзя**.

| # | Компонент | Примечание |
|---|-----------|-----------|
| 1 | Windows 10/11 | — |
| 2 | [AutoHotkey v2](https://www.autohotkey.com/) | Скачать только с официального сайта |
| 3 | Adobe Photoshop | Или любой редактор с поддержкой PNG и прозрачности |
| 4 | CS2 | Запущенная в режиме **«Оконный без рамки»** |

> ⚠️ В режиме **«Полный экран» (Full Screen)** оверлей работать **не будет**.

## 🖼️ Шаг 1. Подготовка изображения прицела в Photoshop

### 1.1. Новый документ

| Параметр | Значение |
|----------|----------|
| Ширина | `1920 px` |
| Высота | `1080 px` |
| Разрешение | `72 ppi` |
| Цветовой режим | `RGB, 8 бит` |
| Содержимое фона | **Прозрачный** |

> ⚠️ Обязательно выберите **«Прозрачный»** фон. Если выбрать «Белый», прицел в игре закроет весь экран белым квадратом.

### 1.2. Направляющие

```
Просмотр → Новые направляющие
  Вертикальная:   960 px
  Горизонтальная: 540 px
```

### 1.3. Рисуем линии

Инструмент **«Прямоугольник»** (клавиша `U`).

| Параметр | Значение |
|----------|----------|
| Толщина | как `cl_crosshairthickness` в CS2 (например, `2` пикс) |
| Цвет | значения RGB из CS2 (например, `#4F00FF` = R:79, G:0, B:255) |

**Вертикальные полосы:**

| Полоса | X | Y | Ш | В |
|--------|---|---|---|---|
| Левая | 959 | 0 | 1 | 1080 |
| Правая | 960 | 0 | 1 | 1080 |

**Горизонтальные полосы** (если нужен полный крест):

| Полоса | X | Y | Ш | В |
|--------|---|---|---|---|
| Верхняя | 0 | 539 | 1920 | 1 |
| Нижняя | 0 | 540 | 1920 | 1 |

> 💡 **Зазор:** в CS2 `cl_crosshairgap` можно поставить `0` — линии сойдутся. Если нужен зазор, сдвиньте полосы на 1–2 пикселя.

> ⚠️ Чтобы полосы были идеально ровными, вводите координаты через панель **«Свойства»** (X, Y, Ш, В), а не рисуйте мышкой.

### 1.4. Скрыть фоновый слой

Убедитесь, что фоновый слой **выключен** (не горит глазик).

### 1.5. Сохранить

```
Файл → Экспортировать → Экспортировать как...
  Формат:     PNG
  Галочка «Прозрачность» — обязательно
  Имя файла:  lineup.png
```

> ⚠️ Не сохраняйте в JPG — он не поддерживает прозрачность, и в игре появится тёмный или белый прямоугольник вокруг прицела.

## ⚙️ Шаг 2. Установка AutoHotkey v2

1. Скачайте установщик **v2.0** с [autohotkey.com](https://www.autohotkey.com/).
2. Запустите. Windows покажет предупреждение SmartScreen — нажмите **«Подробнее → Выполнить в любом случае»**.  
   *Это стандартное предупреждение для новых программ, оно не означает наличие вируса.*
3. Установите в любую папку (можно на диск D — на работу не влияет).
4. После установки закройте окно **AutoHotkey Dash**.

## 📝 Шаг 3. Создание скрипта

### 3.1. Создайте текстовый файл в папке с `lineup.png`

### 3.2. Вставьте код

```autohotkey
#Requires AutoHotkey v2.0
#SingleInstance Force
A_MenuMaskKey := "vkE8"    ; маскировка Win, чтобы не открывался Game Bar

; Настройки оверлея
OverlayAlpha := 180        ; Прозрачность (0-255)
OverlayX_Offset := 0       ; Смещение по X от центра
OverlayY_Offset := 0       ; Смещение по Y от центра
ImageFile := "lineup.png"  ; Имя файла с картинкой

; Получаем разрешение экрана
ScreenW := A_ScreenWidth
ScreenH := A_ScreenHeight

; Создаём окно
MyGui := Gui()
MyGui.Opt("+AlwaysOnTop -Caption +ToolWindow +LastFound +E0x80020")
MyGui.MarginX := 0
MyGui.MarginY := 0
MyGui.BackColor := "000000"
MyGui.Add("Picture", "x0 y0 w" ScreenW " h" ScreenH " BackgroundTrans", ImageFile)

; Прозрачность и клик-сквозность
WinSetTransColor("000000 " OverlayAlpha, MyGui)
WinSetExStyle("+0x20", MyGui)

; Показываем и сразу скрываем
MyGui.Show("x" (ScreenW/2 - (ScreenW/2) + OverlayX_Offset) " y" (ScreenH/2 - (ScreenH/2) + OverlayY_Offset) " w" ScreenW " h" ScreenH " NoActivate")
WinHide("ahk_id " MyGui.Hwnd)

; --- Горячие клавиши ---
XButton2:: {
    WinShow("ahk_id " MyGui.Hwnd)
}
XButton2 Up:: {
    WinHide("ahk_id " MyGui.Hwnd)
}

; Сворачивание игры по одиночному нажатию Win
LWin:: {
    if KeyWait("LWin", "T0.25")
        WinMinimize("A")
}

; Аварийный выход по F12
F12::ExitApp
```

### 3.3. Сохраните как `lineup_overlay.ahk`

> ⚠️ Расширение должно быть **`.ahk`**, а не `.txt`.  
> Включить отображение расширений: `Вид → Показать → Расширения имён файлов`.

## 🖱️ Как поменять кнопку активации оверлея

По умолчанию оверлей включается на **mouse5** (`XButton2`). Найди в коде:

```autohotkey
XButton2:: {
    WinShow("ahk_id " MyGui.Hwnd)
}
XButton2 Up:: {
    WinHide("ahk_id " MyGui.Hwnd)
}
```

И замени `XButton2` **в обеих строках** на нужное значение из таблицы.

### Популярные варианты кнопок

| Кнопка | Название в скрипте |
|--------|-------------------|
| Mouse4 (боковая, ближе к большому пальцу) | `XButton1` |
| Mouse5 (боковая, дальше) | `XButton2` |
| Средняя кнопка мыши | `MButton` |
| Левая кнопка | `LButton` |
| Правая кнопка | `RButton` |
| Колесо вверх | `WheelUp` |
| Колесо вниз | `WheelDown` |
| Колесо влево | `WheelLeft` |
| Колесо вправо | `WheelRight` |
| Клавиша F | `f` |
| Клавиша Space | `Space` |
| Клавиша V | `v` |
| Клавиша H | `h` |
| Клавиша CapsLock | `CapsLock` |
| Клавиши F1–F12 | `F1` … `F12` |
| Клавиша Tab | `Tab` |
| Левый Alt | `LAlt` |
| Левый Ctrl | `LCtrl` |
| Левый Shift | `LShift` |

### Пример: переназначить на Mouse4

```autohotkey
XButton1:: {
    WinShow("ahk_id " MyGui.Hwnd)
}
XButton1 Up:: {
    WinHide("ahk_id " MyGui.Hwnd)
}
```

После правки — **Reload Script** через иконку `H` в трее.

> ⚠️ **Важно при выборе кнопки:**
> - Не назначай на кнопки, занятые в CS2 (стрельба, прыжок, приседание, гранаты, голос).
> - Проверь бинды в консоли: `bind h` покажет, что висит на клавише.
> - Пара `X::` и `X Up::` **обязательна**. Если оставить только первую — оверлей включится и больше не выключится.

## 🔁 Шаг 4. Создание .bat-переключателя (вкл/выкл одной кнопкой)

Чтобы не лазить по папкам и не кликать дважды, создайте `.bat`-файл.

### 4.1. Создайте текстовый файл и вставьте код

```bat
@echo off
title Crosshair Overlay Toggle

tasklist /FI "IMAGENAME eq AutoHotkey64.exe" 2>NUL | find /I "AutoHotkey64.exe" >NUL
if "%ERRORLEVEL%"=="0" goto kill
tasklist /FI "IMAGENAME eq AutoHotkey32.exe" 2>NUL | find /I "AutoHotkey32.exe" >NUL
if "%ERRORLEVEL%"=="0" goto kill
goto start

:kill
taskkill /IM AutoHotkey64.exe /F >NUL 2>&1
taskkill /IM AutoHotkey32.exe /F >NUL 2>&1
echo Overlay OFF
timeout /t 1 >NUL
exit

:start
start "" "C:\CrosshairOverlay\lineup_overlay.ahk"
echo Overlay ON
timeout /t 1 >NUL
```

### 4.2. Замените путь на свой реальный

Строка:
```bat
start "" "C:\CrosshairOverlay\lineup_overlay.ahk"
```

**Как узнать свой путь:**
1. Откройте папку с файлом `lineup_overlay.ahk`.
2. Кликните один раз по адресной строке проводника.
3. Скопируйте путь (`Ctrl + C`).
4. Вставьте его в `.bat` вместо примера, добавив в конце `\lineup_overlay.ahk`.

> ⚠️ Путь должен быть в кавычках. Если в пути есть пробелы, без кавычек `.bat` не сработает.

### 4.3. Сохраните как `Crosshair.bat`

Уберите `.txt`, добавьте `.bat`. Если Windows не даёт переименовать — включите отображение расширений.

### 4.4. Подтвердите предупреждение

Windows может показать «Файл может быть недоступен…» — нажмите **«Да»**.

### Как пользоваться

Просто дважды кликайте по `Crosshair.bat`:

- Если оверлей **выключен** → запустится (иконка `H` в трее).
- Если оверлей **включён** → выключится (иконка исчезнет).

### Горячая клавиша для .bat (опционально)

1. Правой кнопкой по `Crosshair.bat` → **«Отправить» → «Рабочий стол (создать ярлык)»**.
2. На ярлыке: правой кнопкой → **«Свойства»** → поле **«Быстрый вызов»** → нажмите желаемую комбинацию (например, `Ctrl + Alt + X`).
3. **«ОК»**. Теперь оверлей можно включать/выключать с клавиатуры.

## 🎛️ Шаг 5. Управление скриптом

| Действие | Как сделать |
|----------|-------------|
| **Запуск** | Дважды кликнуть по `lineup_overlay.ahk`. В трее появится зелёная иконка `H`. Если не видно — нажмите `^` рядом с часами. |
| **Перезапуск после правок** | Правый клик по иконке `H` → **Reload Script** |
| **Выключение** | Правый клик по иконке `H` → **Exit**. Или используйте `.bat`-переключатель, или `taskkill` (см. Шаг 6). |

> ⚠️ Если выключить компьютер или перезагрузить его, скрипт сам **не запустится**. Каждый раз нужно запускать `lineup_overlay.ahk` вручную (или через `Crosshair.bat`) перед запуском CS2.

## 🖥️ Шаг 6. Управление процессом через консоль (taskkill)

Откройте командную строку (`Win + R` → `cmd`) и выполните одну из команд:

```cmd
taskkill /IM AutoHotkey.exe /F
taskkill /IM AutoHotkey64.exe /F
taskkill /IM AutoHotkey32.exe /F
```

- Если процесс не найден — это нормально, значит скрипт уже выключен.
- В AutoHotkey v2 процесс обычно называется `AutoHotkey64.exe` (на 64-битной системе).
- Команды не содержат имени пользователя — их можно копировать как есть.

## 🎮 Шаг 7. Использование в CS2

1. Запустите CS2.
2. В настройках видео выберите режим **«Оконный без рамки»**.  
   > ⚠️ В режиме «Полный экран» оверлей не будет виден. Это ограничение Windows, а не ошибка скрипта.
3. Зажмите `mouse5` — поверх игры появятся ваши линии. Отпустите — исчезнут.
4. Для сворачивания игры нажмите `Win` (одиночное нажатие).  
   Если зажать `Win` и нажать другую клавишу — сработает системная комбинация.

## 🔧 Настройки скрипта (для тонкой подгонки)

В начале файла `lineup_overlay.ahk` можно изменить:

| Параметр | Описание |
|----------|----------|
| `OverlayAlpha` | Прозрачность (`0` — прозрачный, `255` — непрозрачный). Оптимально `150–200`. |
| `OverlayX_Offset` | Смещение оверлея от центра по X в пикселях. |
| `OverlayY_Offset` | Смещение оверлея от центра по Y в пикселях. |
| `ImageFile` | Имя файла с картинкой, если вы назвали его иначе. |

После правки — **Reload Script** через иконку `H`.

## 🛡️ Безопасность и VAC

- Оверлей **не внедряется** в игру, не читает память, не изменяет файлы. Использует только штатные функции Windows (прозрачное окно).
- VAC не банит за внешние оверлеи, которые не дают нечестного преимущества (например, не показывают врагов через стены).
- Использование в рейтинговых матчах — **на ваш риск**.
- **Не используйте** на турнирах, где запрещены сторонние программы.
- Не запускайте `.ahk`-скрипты из непроверенных источников. Скачивайте AutoHotkey только с [autohotkey.com](https://www.autohotkey.com/).

## 🎨 Дополнительно: смена цветов прицела в игре (chcolor.cfg)

Если хотите быстро менять цвета прицела через консоль — используйте конфиг с алиасами:

```cfg
// chcolor.cfg
alias "chc0"  "cl_crosshaircolor 5; cl_crosshaircolor_r 250; cl_crosshaircolor_g 50;  cl_crosshaircolor_b 50;  echo crosshair: 0 red"
alias "chc1"  "cl_crosshaircolor 5; cl_crosshaircolor_r 50;  cl_crosshaircolor_g 250; cl_crosshaircolor_b 50;  echo crosshair: 1 green"
// ... и так далее
alias "chc_next" "chc_c0"
alias "chc_c0"  "cl_crosshaircolor 5; chc0;  alias chc_next chc_c1"
// ... полный цикл
bind "h" "chc_next"
```

- Для кастомных цветов обязателен `cl_crosshaircolor 5`.
- Сохраните как `chcolor.cfg` (не `.txt`).
- В консоли: `exec chcolor`.
- Клавиша `H` будет переключать цвета по кругу.

> ⚠️ Алиасы (`alias`) в CS2 теперь работают только при загрузке через **autoexec** при запуске игры или вручную через консоль. Загрузить их через `exec` во время игры больше нельзя.
